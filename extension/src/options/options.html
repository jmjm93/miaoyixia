How to add a Chinese voice to Windows
  1. Open Settings → Time & language → Language & region.
  2. Add a language → search for Chinese (Simplified, China) → Next.
  3. Tick Speech (and Text-to-speech if listed). You can untick “Set as my Windows display language” — you only need the voice.
  4. Install, then restart the browser so it picks the new voice up.
