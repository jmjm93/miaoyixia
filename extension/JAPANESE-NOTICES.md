# Optional Japanese data

No Japanese dictionary or language models are included in the extension package. They are
downloaded only when the user explicitly enables/downloads Japanese in Options.

## JMdict

JMdict is copyright James William Breen and the Electronic Dictionary Research and Development
Group (EDRDG). Japanese and English dictionary data are provided under Creative Commons
Attribution-ShareAlike 4.0. The local lookup tables derived from that data remain under that licence.

- Project and documentation: https://www.edrdg.org/jmdict/j_jmdict.html
- Licence and attribution requirements: https://www.edrdg.org/edrdg/licence.html
- Licence text: https://creativecommons.org/licenses/by-sa/4.0/legalcode
- JSON distribution: https://github.com/scriptin/jmdict-simplified
- Pinned release: `3.6.2+20261005200550`, English full dictionary

## Tesseract Japanese models

The `jpn` and `jpn_vert` traineddata files come from the Tesseract project's `tessdata_fast`
release `4.1.0` and are distributed under Apache License 2.0.

- Project: https://github.com/tesseract-ocr/tessdata_fast
- Licence text: https://github.com/tesseract-ocr/tessdata_fast/blob/4.1.0/LICENSE

These files are data used by the already bundled Tesseract engine. No executable code is
downloaded with the Japanese add-on.
